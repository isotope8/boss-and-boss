# Boss & Boss

A Reigns-style swipe game about running a Malaysian company when you're also the HR department.
Keep Cash, Morale, Compliance and Reputation in balance for 3 years.

**Play:** https://isotope8.github.io/boss-and-boss/

- 78 base situations + 10 industry expansion packs (E&E, palm oil, oil & gas, mamak, resort, construction, logistics, banking, hospital, tech)
- English, Bahasa Melayu, 华文, தமிழ்
- End-of-run debrief: HR style, people-first vs profit-first, law lessons, hiring-bias patterns
- Workshop mode: the same code gives a whole room the same situations

Employment rules are simplified for gameplay and are not legal advice.

## Add an expansion pack
Copy `packs/_template.js`, fill it in, and add one `<script src="packs/your-pack.js">` line in `index.html`.

## Run locally
Open `index.html` in a browser. No server needed.
