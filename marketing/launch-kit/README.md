# Launch kit

Open `index.html` in a browser. It has the plan, every caption with a Copy button, and links to each ready-made file.

- `ready/` — files to upload, numbered in the order to use them. The file name says where each one goes.
- `CAPTIONS.md` — every caption in plain text (EN and BM).
- `source/` — the scripts and pages used to make the files (`build_kit.py` rebuilds `index.html` and `CAPTIONS.md` from `kitcopy.py`).

The game link box is pre-filled with https://isotope8.github.io/boss-and-boss/. Add your WhatsApp or email in the contact box and the captions update.
